# RugbyZone - Tienda e Información de Rugby

## Propósito de la Página

**RugbyZone** es una plataforma web desarrollada para apasionados, jugadores y fanáticos del rugby. El objetivo principal del sitio es presentar de forma atractiva e intuitiva una catálogo de productos e indumentaria de rugby, mostrar contenido multimedia relevante y proporcionar una vía de comunicación directa a través de un formulario funcional.

## Estructura y Características Técnicas

1. **HTML5 Semántico**: Maquetación ordenada utilizando `<header>`, `<nav>`, `<main>`, `<section>` y `<footer>`.
2. **Formulario de Contacto**: Integrado con **Formspree** para permitir la recepción real de mensajes.
3. **CSS3**: Archivo de estilos externo (`styles.css`), con fuentes integradas de **Google Fonts** ('Montserrat' y 'Roboto') y propiedades de fondo avanzadas (combinación de imagen y degradado).
4. **Layout Responsivo**:
   - **Flexbox**: Aplicado para la distribución dinámica de las tarjetas de productos.
   - **CSS Grid**: Implementado en la sección de reseñas para lograr una cuadrícula equilibrada.
   - **Media Queries**: Utilizadas para adaptar la navegación, tipografías y secciones del sitio a dispositivos móviles y tablets.
5. **Navegación e Integración Multimedia**: Incluye un menú de navegación por anclas internas y la integración de un reproductor interactivo mediante `<iframe>` para videos.
